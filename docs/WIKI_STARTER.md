# Wiki starter content

GitHub's Wiki (Settings → Features → Wikis) isn't included in a repo zip/clone,
so this file holds the starting content to paste in once the repo is pushed —
create these as wiki pages:

- **Home** — project overview, link back to README and docs/
- **Decision Log** — running list of non-obvious decisions and why (start from
  the "Key Design Decisions" table in docs/ARCHITECTURE.md, then add new ones
  as they come up — this is where deltas from the original plan get recorded)
- **FAQ** — accumulate real questions reviewers/contributors ask
- **Local Dev Troubleshooting** — common docker compose / Flyway / port-conflict issues

Everything that belongs in the README stays in the README; the wiki is for
material that would make the README too long to skim in a minute.
